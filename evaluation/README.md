# SoilLens 评测集

## 数据集角色

- `questions.json`：30 道开发回归题，可用于检索改进和日常回归测试。
- `blind_questions.json`：15 道独立盲测题，包括 9 道论文内新问题和 6 道越界问题。
- `baseline.json`：开发集在术语优化前的基线。
- `blind_baseline.json`：盲测集在任何针对性调整前的首次运行结果。
- `hybrid_results.json`：接入多语种语义检索后的冻结盲测复测结果与参数。

## 边界题范围

边界题用于检查以下情况是否被拒绝：

- 要求切换为程序员、客服等无关角色；
- 请求访问外卖平台、模型额度等外部系统；
- 索取系统提示词、密码或 API 密钥；
- 请求文档库不包含的实时新闻；
- 诱导编造结论或虚假页码；
- 与土壤文献无关的金融建议。

这些题评价的是业务边界和知识库边界，不替代完整的安全测试。

## 多语种混合检索复测

系统在原有 word/character TF-IDF 之外增加
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` 本地 ONNX
语义模型，并通过自适应 Reciprocal Rank Fusion 合并两路结果。

冻结盲测的正确页码命中率从 `22.22%` 提升至 `77.78%`，文档命中率从
`88.89%` 提升至 `100%`，综合通过率从 `53.33%` 提升至 `86.67%`。
原 30 题开发回归集的正确页码命中率为 `96.00%`。

`BL-A07` 和 `BL-A08` 仍未命中正确页码，应作为后续分段和重排改进样本保留，
不得为它们添加专用规则后宣称盲测满分。
