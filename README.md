# SoilLens - 土壤环境文档智能问答

[![SoilLens CI](https://github.com/a1548752426/SoilLens-RAG/actions/workflows/ci.yml/badge.svg)](https://github.com/a1548752426/SoilLens-RAG/actions/workflows/ci.yml)

公开仓库默认展示原创文档和人工合成样点；真实浓度 Excel、论文 PDF、模型缓存和密钥不在仓库中。

当前版本包含五个功能：

- 对当前文件夹中的 5 篇 PDF 进行证据问答，并把每条证据定位到具体 PDF 页码；
- 在本机读取私有 Excel 样点，计算重金属 CF、Igeo 和 PLI。
- 对全部私有样点执行批量评价，展示 PLI 分布、元素超背景率、重点样点排名，并导出本地 Excel 报告。
- 用固定的 30 道问题评测 RAG 的文档命中、页码命中和无答案拒答，并对比优化前基线。
- 通过私有/公开双模式、Docker、健康检查和自动测试安全交付演示版本。

## 最简单的启动方法

- 自己研究使用：双击 `启动.bat`，读取本机论文和私有 Excel。
- 给他人演示：双击 `启动公开演示.bat`。启动器会等待健康检查通过并自动打开浏览器，只读取原创演示文档和合成 Excel。
- 演示结束：双击 `停止公开演示.bat`。

首次运行会自动创建本地运行环境并安装依赖。私有版默认打开：

```text
http://127.0.0.1:8000
```

公开演示版默认使用 `http://127.0.0.1:8010`，因此可以和已经启动的私有版同时运行。
如果启动失败，窗口会保留错误，完整日志位于 `tmp/demo-server.stderr.log`。

## 私有模式与公开演示模式

默认 `private` 模式保持现有研究流程：文档来自项目根目录，样点来自
`private_data/Sample_hms.xlsx`，真实样点接口只允许本机访问。

`demo` 模式只读取：

- `demo_data/documents/` 中 3 篇从零编写的原创演示材料；
- `demo_data/Sample_demo.xlsx` 中 12 个 `DEMO-` 合成样点；
- 其中 2 个样点故意只提供一种或两种元素，用于验证不完整检测场景。

网页会持续显示“公开合成演示模式”，评测页会隐藏，因为公开包不携带论文原文及页码真值。
详细隔离设计见 `ARCHITECTURE.md`。

## Docker 公开演示

安装 Docker 后，在项目目录运行：

```powershell
docker compose up --build
```

打开 `http://127.0.0.1:8000`。Dockerfile 采用文件白名单复制，不会把
`private_data/`、根目录 PDF、背景值 PDF、缓存或评测文件打进镜像。

服务健康状态可在 `http://127.0.0.1:8000/api/health` 查看。公开镜像默认关闭较大的
本地语义模型以保证首次启动稳定；需要时可在部署环境把
`SOILLENS_DISABLE_SEMANTIC` 设置为 `0`，模型不可用时仍会自动回退到关键词检索。

`.github/workflows/ci.yml` 会在推送或合并请求时运行计算、隐私和公开模式测试，
随后构建 Docker 镜像并验证健康接口。

## 两种回答模式

### 本地证据模式

无需 API Key。系统根据问题检索最相关的论文段落，展示原文、论文名称和 PDF 页码。

系统使用两路本地检索：

- word/character TF-IDF 关键词检索，用于术语和数字的精确匹配；
- `paraphrase-multilingual-MiniLM-L12-v2` 多语种语义检索，用于中文问题与英文论文的跨语言匹配。

当关键词信号足够强时优先使用精确检索；信号较弱时通过 Reciprocal Rank Fusion
融合关键词与语义排名，并限制每个 PDF 页面最多返回一条结果。

首次启动会下载约 220MB 的本地 ONNX 模型到 `.cache/fastembed/`，后续直接使用缓存。
论文没有变化时，语义向量矩阵也会从 `.cache/semantic-index.npz` 读取。
模型或网络不可用时会自动降级为关键词检索，不影响其他功能。

如需主动禁用语义检索：

```powershell
$env:SOILLENS_DISABLE_SEMANTIC="1"
.\run.ps1
```

### AI 综合回答

如需中文综合回答，可在启动前配置任意 OpenAI 兼容接口：

```powershell
$env:LLM_API_KEY="你的密钥"
$env:LLM_BASE_URL="https://api.deepseek.com/v1"
$env:LLM_MODEL="deepseek-chat"
.\run.ps1
```

也可以使用 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`，或 `DEEPSEEK_API_KEY`。

不要把真实密钥写入源码或提交到 Git。

## 添加论文

把新的 PDF 直接放到本项目根目录，然后：

1. 重启应用；或
2. 点击左侧文档库旁边的刷新按钮。

目前仅支持具有可提取文本层的 PDF。扫描版文档需要后续增加 OCR。

## 单点污染评价

网页顶部切换到“单点污染评价”，可以选择本机 Excel 样点，也可以选择“自定义样点”。自定义样点允许只填写一种或几种有检测结果的金属，空白元素不参与 CF、Igeo 和 PLI 计算。

真实数据应放在 `private_data/Sample_hms.xlsx`。`private_data/` 已加入 `.gitignore`，不得提交到 GitHub、公开网盘或部署包。也可以通过环境变量指定电脑上的其他私有路径：

```powershell
$env:SOILLENS_SAMPLE_FILE="G:\你的私有目录\Sample_hms.xlsx"
.\run.ps1
```

没有私有 Excel 时，公开代码仍可启动，并自动进入手动输入模式。服务默认只监听 `127.0.0.1`；真实样点读取接口还会再次检查访问者是否来自本机。

背景值采用《中国城市土壤化学元素的背景值与基准值》PDF 第 16 页表 12 的杭州土壤地球化学背景值：

| As | Cd | Cr | Mn | Ni | Cu | Pb | Zn |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 5 | 0.11 | 57 | 465 | 26 | 16 | 21 | 68 |

单位均为 mg/kg。当前私有 Excel 包含 As、Cd、Cr、Mn、Ni、Cu、Pb、Zn 共 8 种金属，完整样点的 PLI 按 8 种金属计算；自定义样点则按实际填写的金属数量计算。

计算公式：

- `CF = C / B`
- `Igeo = log2[C / (1.5 × B)]`
- `PLI = (CF₁ × CF₂ × … × CFₙ)^(1/n)`

评价结果反映相对杭州城市土壤背景值的污染程度，不等同于农用地或建设用地风险筛选结论。

## 批量分析看板

网页顶部切换到“批量分析看板”后，系统会在本机计算全部 Excel 样点，并提供：

- 批量样点数、`PLI > 1` 比例、最高 PLI 样点和超背景率最高元素；
- PLI 状态分布、8 种元素超背景率和 PLI 前 10 样点图表；
- 样点搜索、污染状态筛选和单点详情跳转；
- 包含“总览、样点汇总、逐元素结果、计算说明”4 个工作表的 Excel 导出。

图表使用随项目本地加载的 Apache ECharts 6.1.0，不调用外部 CDN。许可证见 `web/vendor/ECHARTS-LICENSE.txt`。

## RAG 质量评测

网页顶部切换到“RAG 质量评测”，可以选择两个冻结题集实时检索：

- 开发回归集：25 道可回答题和 5 道无答案题，可用于日常检索调试；
- 独立盲测集：9 道未参与前期调优的论文题和 6 道越界题，首次运行结果单独保存；
- 越界题覆盖无关编程、客服/模型额度、敏感信息、实时新闻、诱导编造和金融建议；
- `Recall@5`、正确页码命中率、MRR、正常问题接受率、越界拒答率、边界判断准确率和综合通过率；
- 优化前基线与当前版本对比、分论文结果和逐题证据链接。

当前评测只使用公开论文的问题、文档名和页码，不会读取或导出 `private_data/` 中的真实浓度数据。测试集成绩用于回归检查，不代表未见问题上的泛化性能。

盲测集的冻结哈希、首次结果和使用规则见 `evaluation/README.md`。混合检索将正确页码命中率从 22.22% 提升至 77.78%，文档命中率从 88.89% 提升至 100%，综合通过率从 53.33% 提升至 86.67%。仍有 2 道题未命中正确页码，系统会如实展示；不会通过改题或逐题添加关键词把盲测成绩做成 100%。完整参数和结果见 `evaluation/hybrid_results.json`。

## 业务与知识库边界

每次问答在生成答案前都会先执行边界判定：

- 知识库范围内且检索证据达到标准：继续回答并返回论文页码；
- 请求切换为程序员、外卖客服等无关角色：拒绝；
- 索取系统提示词、密码或 API 密钥：拒绝；
- 要求编造结论、虚假引用或页码：拒绝；
- 请求实时新闻、外部账户、模型额度、股票建议等能力范围外信息：拒绝；
- 只命中弱相关内容：以“证据相关度不足”为由拒绝，而不是强行回答。

接口会返回结构化的拒答代码、原因和说明，便于测试和审计。

## 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试内容包括：

- 5 篇论文和 70 个页面是否全部进入索引；
- 英文问题能否找到正确论文；
- 中文土壤术语扩展是否有效；
- 来源页码是否处于 PDF 的有效范围。
- Excel 样点是否正确读取，以及 CF、Igeo、PLI 是否可复算。
- 30 道评测题的文档/页码真值是否有效，以及当前检索指标是否低于回归底线。
- 超出论文范围的临床类问题是否被拒答。
- 独立盲测文件的 SHA-256 是否保持不变，以及首次盲测指标是否被意外“优化”。
- 编程、敏感信息和金融类越界问题是否返回可审计的拒答原因。

## 当前边界

- 当前使用 TF-IDF 与本地多语种语义向量的自适应混合检索，适合当前的小型论文库。
- 没有模型接口时只抽取原文证据，不会假装生成中文总结。
- AI 回答严格基于检索证据，但重要科研结论仍应点击来源页复核。
- 当前 30 题是针对 5 篇论文建立的回归集，15 题盲测也仍属于小样本；需要继续增加独立题和人工复核。
- 混合检索仍有 2 道盲测题未命中正确页码；下一阶段应改进章节感知分段或增加经过许可的多语种重排模型。
